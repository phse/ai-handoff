# Demo Shop

Online shop for handmade ceramics. Nuxt front end, Node API.

@docs/conventions.md

## Commands

Run the dev server with `npm run dev`. Deploys and logins are done by the
developer - propose them with handoff_propose_command.

## Release checklist

Always run the release script from the project root folder so that the
relative paths in the build configuration resolve correctly every time.

Design notes for the checkout live in ./docs/checkout-design.md (read when working on checkout).
